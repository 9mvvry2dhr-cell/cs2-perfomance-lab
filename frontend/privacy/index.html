3. Какие данные обрабатываются

  • Steam ID пользователя;
  • технические данные авторизационной сессии;
  • IP-адрес в технических журналах сервера;
  • загружаемый пользователем файл матча .dem;
  • результаты и игровые показатели, полученные из .dem;
  • технические сведения о заданиях анализа.

Steam-имя и аватар могут кратковременно запрашиваться для отображения интерфейса и не сохраняются постоянно в основной базе. Данные остальных игроков из матча сохраняются без их реальных Steam ID и игровых имён.

4. Цели обработки

  • авторизация пользователя через Steam;
  • предоставление функций анализа матчей;
  • ведение истории анализов пользователя;
  • защита сервиса, диагностика ошибок и обеспечение безопасности;
  • обработка обращений пользователей.

5. Сроки хранения

  • файл .dem — удаляется после завершения или ошибки анализа;
  • сессия авторизации — до 30 дней либо до выхода/отзыва;
  • технические данные задания анализа — до 30 дней;
  • история матчей и аналитика — до 90 дней;
  • Steam ID аккаунта — пока пользователь пользуется сервисом, а при запросе на удаление удаляется вместе с данными аккаунта;
  • технические журналы сервера ротируются автоматически по установленному ограничению объёма.

6. Использование AI

Для формирования текстового объяснения игровых показателей сервис может использовать внешний AI-сервис. В такой запрос не включаются Steam ID, ник пользователя, IP-адрес, cookie авторизации, исходный .dem-файл или идентифицирующие данные других игроков. Передаются игровые метрики и результаты автоматического анализа.
